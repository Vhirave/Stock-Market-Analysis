# Stock-Market-Analysis

This project focuses on analyzing stock market and listed company data to identify trends, patterns, and insights that can support financial decision-making.
The project involves extracting raw stock market datasets, performing ETL (Extract, Transform, Load) processes, cleaning the data, and preparing it for analysis and visualization.

🔹 Project Workflow
Data Extraction &Collected raw stock market data and company information from available datasets.
ETL Process (Excel – Power Query) Extracted and transformed raw datasets then Standardized data formats and structured the data for analysis.
Data Cleaning (Power BI)-Removed duplicates and irrelevant columns - Handled missing values and inconsistent records - Ensured data quality and consistency - Prepared the dataset for analytical use - Created meaningful data structures for analysis.
Database Storage (MySQL) - Loaded the cleaned dataset into a MySQL database - Enabled efficient querying and data management.

🔹 Tools & Technologies Used
Excel (Power Query) – ETL Process
Power BI – Data Cleaning and Visualization
MySQL – Database Storage and Querying
SQL – Data Manipulation and Analysis

🔹 Key Objectives
Understand stock market data structure
Perform ETL on raw financial datasets
Clean and transform data for analytical use
Store structured data in a relational database
Enable efficient analysis and reporting
